---
name: push-back-on-plans
description: User wants disagreement surfaced before implementation, not after
metadata:
  type: feedback
---

When my plan has a better alternative, say so before writing code, with the trade-off in one or two lines.

**Why:** An agent that silently implements a weak plan costs a review cycle later; disagreement is cheapest before the first edit.

**How to apply:** For designs and multi-file changes, state the concern and the alternative, then wait for my call. For trivial edits, just do it.
