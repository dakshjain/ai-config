# Spec Kit (github/spec-kit) — use for ALL coding tasks
`specify` CLI installed via `uv tool install specify-cli --from git+https://github.com/github/spec-kit.git` (upgrade: `specify self upgrade`).
For every coding task (features, bug fixes, refactors):
1. If repo root has no `.specify/`, run `specify init --here --force --integration claude --script sh --non-interactive` first (adds `.specify/` + `.claude/skills/speckit-*`). In a non-git dir or shared/monorepo root, ask before initializing.
2. Follow the flow via the skills: `/speckit-constitution` (once per repo) → `/speckit-specify` → `/speckit-clarify` (if ambiguous) → `/speckit-plan` → `/speckit-tasks` → `/speckit-analyze` → `/speckit-implement`.
3. Trivial edits (typo, 1-2 line fix, config tweak) may skip straight to the edit; say so in one line.
